# MOEX FORTS — скринер секундных прострелов

Читает полную ленту сделок срочного рынка Мосбиржи и шлёт алерт в Telegram на каждый **принт, улетевший на ±2% и больше за секунду**.

## Что считается прострелом
Сделка, цена которой отличается от рынка на ≥ `THRESHOLD`% (по умолчанию 2%). Рынок берётся одним из двух способов, побеждает большее отклонение:
- **медиана последних 5 сделок** по тикеру за 10 секунд до текущей секунды. Медиана нужна, чтобы возврат цены после шпильки не считался вторым прострелом;
- **первая сделка текущей секунды**. Так ловится проход стакана внутри одной секунды.

Если за 10 секунд перед принтом по тикеру не было сделок, сравнивать не с чем, и алерта не будет. Это отсекает неликвид, где между сделками проходят минуты.

Внебиржевые (адресные) сделки игнорируются: их цена бывает произвольной.

Повторный алерт по тикеру в ту же сторону приходит не раньше чем через 30 секунд. Исключение: принт ушёл ещё на 1% дальше.

Пример алерта:
```
🚀 QQQF (NASD-…) принт +2.47% за секунду
659 → 675.3 | 11 лот, покупка
биржа 11:00:00 (задержка 15 мин)
```

## Настройки (переменные окружения в Render → Environment)
| переменная | по умолч. | что делает |
|---|---|---|
| `TG_TOKEN` | — | токен бота от @BotFather |
| `TG_CHAT_ID` | — | куда слать алерты. Можно несколько через запятую: `123456789,@my_channel` (см. ниже) |
| `FINAM_SECRET` | — | токен Finam Trade API: данные в реальном времени (см. ниже) |
| `THRESHOLD` | `2` | порог прострела, % |
| `MIN_TRADES` | `30` | минимум сделок за день по тикеру; `0` — все фьючи, включая неликвид |
| `REF_MAX_AGE` | `10` | рынок = сделки не старше N секунд до принта |
| `REF_TRADES` | `5` | сколько последних сделок брать в медиану |
| `COOLDOWN` | `30` | пауза между алертами по тикеру в одну сторону, сек |
| `PUBLIC_BOT` | `1` | `0` выключает команды /start и /stop для других людей |
| `ONLY` | — | только эти тикеры или активы через запятую: `Si,BR,MX,GD` |
| `EXCLUDE` | — | исключить тикеры или активы |
| `MOEX_LOGIN`, `MOEX_PASSWORD` | — | логин и пароль MOEX Passport с подпиской ISS: данные без задержки |

## Вечники на американские акции (🇺🇸)
Вечные фьючерсы FORTS на акции и индексы США (QQQF, SP500F, TSLAF, AMDF, NBISF, AMZNF, NFLXF, COINF, HOODF и другие) выделены в отдельную группу:
- **фильтр по числу сделок не действует.** Они неликвидны, у многих меньше 30 сделок за день;
- **рынок для сравнения берётся за 60 секунд**, а не за 10, потому что сделки по ним идут реже;
- **в Финаме подписываются всегда и первыми**, независимо от `FINAM_MAX_STREAMS`;
- **в алерте пометка 🇺🇸.**

| переменная | по умолч. | что делает |
|---|---|---|
| `US_PERPS` | список из кода | полный список тикеров US-вечников через запятую |
| `US_PERPS_ADD` | — | добавить новые тикеры к списку по умолчанию, например `NVDAF,AAPLF` |
| `US_REF_MAX_AGE` | `60` | окно для рынка по US-вечникам, сек |
| `US_PERPS_ON` | `1` | `0` выключает особые правила для US-вечников |

Когда биржа запускает новый вечник на акцию США, его можно добавить через `US_PERPS_ADD` без правки кода.

## Источник данных и задержка
- **Finam Trade API, реальное время.** Включается, если задана переменная `FINAM_SECRET`. На каждый фьючерс открывается свой поток сделок (так устроен API Финама), и алерт приходит через 1–2 секунды после принта.
- **MOEX ISS, задержка около 15 минут.** Работает без брокера, если `FINAM_SECRET` не задан. Прострелы ловятся все, но алерт приходит через 15 минут.

Источник, который сейчас используется, показан вверху дашборда.

### Finam
| переменная | по умолч. | что делает |
|---|---|---|
| `FINAM_SECRET` | — | секретный токен Trade API из кабинета Финама |
| `FINAM_MAX_STREAMS` | `200` | максимум фьючей, на которые подписываться. Самые ликвидные идут первыми |
| `FINAM_OPENS_PER_MIN` | `90` | сколько потоков открывать в минуту. У Финама лимит на частоту запросов; при `local_rate_limited` в логах уменьши |
| `FINAM_FUT_MIC` | `RTSX` | код биржи для фьючей, если справочник Финама недоступен |

При запуске в лог пишутся квоты API (`[finam] квота …`) и число найденных фьючей. Если Финам режет число подписок, уменьши `FINAM_MAX_STREAMS`.

## Деплой: Render + пингер
1. Залей репозиторий на GitHub.
2. На https://dashboard.render.com нажми **New → Blueprint** и выбери репозиторий. Впиши `TG_TOKEN` и `TG_CHAT_ID`, нажми **Apply**.
3. Когда статус станет **Live**, в Telegram придут «🔌 Скринер MOEX стартует…» и «✅ Скринер запущен…». Дашборд откроется по адресу сервиса.
4. На https://cron-job.org создай задачу: `https://<сервис>.onrender.com/health` каждые 5 минут. Без неё free-сервис засыпает через 15 минут без запросов.

Если сообщений в Telegram нет, смотри строки `[tg]` во вкладке **Logs**. Там будет точная причина: неверный токен, chat id или у бота не нажат Start.

## Где взять TG_TOKEN и TG_CHAT_ID
1. В @BotFather отправь `/newbot` и получи токен вида `123456:AAH...`.
2. Открой своего бота, нажми **Start** и напиши что-нибудь.
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьми число из `"chat":{"id":...`. Это не число из токена.

## Публичный бот: алерты для всех
Любой человек находит твоего бота в Telegram, жмёт **/start** и начинает получать алерты.
- `/start` — подписаться
- `/stop` — отписаться
- `/porog 3` — свой порог, например только прострелы от 3%. Ниже `THRESHOLD` поставить нельзя
- `/status` — свои настройки и состояние скринера

Список подписчиков хранится файлом `subscribers.json`, закреплённым в **твоём** чате с ботом. Твой чат — первый id в `TG_CHAT_ID`. **Не открепляй и не удаляй это сообщение**: по нему бот восстанавливает подписчиков после перезапуска. Файл обновляется сам.

Ты получаешь алерты всегда, без /start. Если человек заблокировал бота, он сам удаляется из списка. Выключить публичный режим можно переменной `PUBLIC_BOT=0`.

Можно слать алерты и в Telegram-канал: допиши его в `TG_CHAT_ID` через запятую (`123456789,@my_channel`) и сделай бота админом канала.

## Локальный запуск
```bash
pip install -r requirements.txt
TG_TOKEN=... TG_CHAT_ID=... PORT=8080 python moex_spike_screener.py
```
Флаг `--test-alert` шлёт тестовый алерт и завершает работу.
